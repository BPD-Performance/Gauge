Connecting

After the first time you connect, the app looks for the gauge by itself each time it opens (needs a recent version of Chrome). If it can't, just tap Connect.
Developer tools

For testing and bench work only. Nothing here is needed to use the gauge in the car.

Demo mode

The app makes up realistic data by itself (idle, a full-throttle run with boost, then off the throttle) so you can try every page without the gauge. It stops as soon as a gauge connects.

Bench test

Makes the gauge generate realistic fake Haltech data (a 24 second loop: idle, a full-throttle run through 1st to 4th with boost, then idle). The gauge and this app behave as if the car is running. It switches off by itself on restart or if real ECU data appears, and keypad frames are never sent to the car while it runs. Boost + and − on the Keypad tab move the simulated target boost.

Command console
